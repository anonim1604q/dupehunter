# dupehunter

Быстро находит дубликаты файлов и **безопасно** их чистит. Только стандартная библиотека Python: без зависимостей, работает на Linux, macOS и Windows.

[English](README.md) | [Русский](README.ru.md)

## Зачем

Фото, загрузки и бэкапы незаметно забивают диск копиями. `dupehunter` находит их, не читая каждый файл целиком, и ничего не трогает, пока вы не разрешите.

## Возможности

- **Быстрый поиск в 3 этапа**: группировка по размеру, затем хеш первых 64 КиБ, и полный хеш только у реальных кандидатов (BLAKE2b, многопоточно).
- **Безопасно по умолчанию**: только чтение. Действия работают в режиме *пробного запуска*, пока нет `--apply`.
- **Перепроверка байтов** перед каждым удалением, перемещением или хардлинком: файл, изменившийся после скана, пропускается.
- **Умная обработка**: симлинки игнорируются, хардлинки не считаются дубликатами, пустые файлы пропускаются.
- **Три действия**: `--delete`, `--move-to DIR`, `--hardlink` (атомарная замена, файл никогда не пропадает).
- **Какую копию оставить**: `--keep oldest|newest|shortest` (самый короткий путь).
- **Для автоматизации**: вывод `--json`, код возврата `--fail-on-dupes` для CI.

## Установка

```bash
pipx install git+https://github.com/<your-username>/dupehunter
# или без установки:
git clone https://github.com/<your-username>/dupehunter && cd dupehunter
python -m dupehunter --help
```

Нужен Python 3.9+.

## Примеры

```bash
# Только отчёт (ничего не меняется)
dupehunter ~/Pictures ~/Downloads

# Только файлы от 5 МиБ, пропустить папки
dupehunter ~/Downloads -m 5M -x node_modules -x '*.tmp'

# Сначала предпросмотр, потом реально перенести лишние копии
dupehunter ~/Pictures --move-to ~/dupes --keep oldest
dupehunter ~/Pictures --move-to ~/dupes --keep oldest --apply

# Заменить копии хардлинками: место экономится, все пути работают
dupehunter ~/backup --hardlink --apply

# JSON для скриптов
dupehunter ~/data --json > dupes.json

# Проверка в CI: упасть, если в репозитории есть дубли ассетов
dupehunter ./assets --fail-on-dupes -q
```

## Опции

| Опция | Описание |
|---|---|
| `-m, --min-size SIZE` | Игнорировать файлы меньше SIZE (`10K`, `5M`, `1G`) |
| `-x, --exclude GLOB` | Пропускать подходящие файлы и папки (можно повторять) |
| `--hidden` | Включить скрытые файлы и папки |
| `--keep POLICY` | `oldest` (по умолчанию), `newest`, `shortest` |
| `--delete` / `--move-to DIR` / `--hardlink` | Действие над лишними копиями (взаимоисключающие) |
| `--apply` | Реально выполнить действие (по умолчанию пробный запуск) |
| `-y, --yes` | Не спрашивать подтверждение |
| `--json` | Отчёт в JSON |
| `--fail-on-dupes` | Код возврата 1, если найдены дубликаты |
| `-j, --jobs N` | Число потоков хеширования |
| `-q, --quiet` | Без вывода прогресса |
